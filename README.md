# Notebooks.com.ar — Documentación de producto

Comparador de precios de notebooks en Argentina. Indexa publicaciones de tiendas de terceros; no vende ni intermedia pagos.

## Documentos

1. **[01-investigacion-de-mercado.md](01-investigacion-de-mercado.md)** — Contexto macro, competidores (HardGamers, PreciosGamer, Precialo), referentes internacionales (SoloTodo, Idealo) y conclusiones.
2. **[02-propuesta-de-producto.md](02-propuesta-de-producto.md)** — Posicionamiento, secciones del sitio, funcionalidades core, qué no hacer, métricas norte.
3. **[03-modelos-de-negocio.md](03-modelos-de-negocio.md)** — Cinco verticales analizadas con sus puntos débiles y recomendación de secuencia por fases.
4. **[04-prompt-de-desarrollo.md](04-prompt-de-desarrollo.md)** — Documento-prompt para desarrollar el sitio: stack, modelo de datos, pipeline de ingesta/matching, rutas, fases y criterios de aceptación. Contiene `[DECISIÓN PENDIENTE]` a resolver antes de ejecutar.

## Tesis central

El nicho "notebooks" está vacante en Argentina: HardGamers domina componentes gamer pero nadie ofrece fichas únicas por modelo con specs normalizadas e historial de precios. El índice completo y objetivo es el producto; se monetiza por fases: afiliación → publicidad/destacados → CPC → datos B2B. Cobrar por listar está descartado como modelo de entrada.
